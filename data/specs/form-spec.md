# 表单字段规范（RAG 检索用）

## 手机号 phone
- 类型：tel，必填；占位提示“请输入11位手机号”。
- 校验：11 位数字，以 1 开头。

## 姓名 name
- 类型：text，必填；长度 2~20。

## 邮箱 email
- 类型：email，非必填；需符合邮箱格式。

## 地址 address
- 类型：textarea，非必填；支持多行输入。

## 城市 city
- 类型：select；选项为 上海 / 北京 / 广州 / 深圳。

## 通用要求
- 字段标识使用蛇形命名（snake_case）。
- 同一表单内字段 name 不可重复。
- 必填字段需在前端做提交前校验。

## 可选字段类型（前端已全部支持）
| 类型 | 控件 | 说明 |
|---|---|---|
| text | 单行输入 | 通用文本 |
| tel | 单行输入 | 电话号码，校验数字位数 |
| email | 单行输入 | 邮箱格式校验 |
| password | 密码输入 | 密文显示 |
| textarea | 多行输入 | 地址、备注等长文本 |
| number | 数字输入 | 年龄、数量、金额 |
| select | 下拉选择 | 必须给 options |
| radio | 单选组 | 必须给 options，如性别 |
| checkbox | 多选组 | 必须给 options，如兴趣爱好 |
| switch | 开关 | 布尔值，如“已阅读并同意条款” |
| date | 日期选择 | 生日、活动日期 |
| time | 时间选择 | 具体到时分 |
| datetime | 日期时间选择 | 预约时间 |
| upload | 附件上传 | 照片、证件、证明材料 |
| url | 网址输入 | 官网、作品链接 |

## 选项约定
- select / radio / checkbox 的 `options` 必须是字符串数组，不要嵌套对象。
- switch 不需要 options，标签直接写业务含义（如“我已阅读并同意相关条款”）。
